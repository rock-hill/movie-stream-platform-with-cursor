# 動画配信プラットフォーム 要件定義書

## 1. アプリケーション概要

Udemy Clone風の動画配信プラットフォームを構築します。
月額制の動画配信サービスを想定していますが、今回はデモ版として実装します。

## 2. 認証・決済について

- **認証機能**: なし（デモ版のため）
- **決済機能**: なし（デモ版のため）
- **アクセス制限**: なし（誰でも無料で全コンテンツにアクセス可能）

## 3. 動画配信について

- **動画ソース**: YouTube埋め込みを使用
- **動画形式**: YouTubeの埋め込みプレーヤーを使用して動画を再生

## 4. 機能要件

### 4.1 トップページ（コース一覧ページ）

- 複数のコースが一覧表示される
- 各コースカードには以下の情報を表示：
  - コース画像/サムネイル
  - コースタイトル
  - コースの概要説明
- コースカードをクリックすると、コース詳細ページに遷移

### 4.2 コース詳細ページ

- コースの詳細情報を表示：
  - コースタイトル
  - コース説明
  - コースのカリキュラム（セクション一覧）
  - その他のコース情報
- 「コースを見る」ボタンを配置
- 「コースを見る」ボタンをクリックすると、動画視聴ページに遷移

### 4.3 動画視聴ページ

- Udemy風のレイアウトで実装：
  - 左側：動画プレーヤー（YouTube埋め込み）
  - 右側：コースのカリキュラム（セクション・動画一覧）
- セクションごとに動画が整理されている
- 各セクションには複数の動画が含まれる
- 動画を選択すると、左側のプレーヤーで再生される
- **動画完了機能**: 
  - 一つの動画を見終わったら、自動的に次の動画に進む機能
  - または、次の動画への遷移ボタンを表示

## 5. UI/UX要件

- Udemyのようなモダンで使いやすいデザイン
- レスポンシブデザイン（PC・タブレット・スマートフォン対応）
- 直感的なナビゲーション

## 6. 技術要件

- **フレームワーク**: Next.js（既存プロジェクト）
- **動画埋め込み**: YouTube IFrame API または YouTube埋め込みタグ
- **状態管理**: 動画の視聴状況、現在のセクション・動画の管理

## 7. データ構造（想定）

### コース（Course）
- id
- title
- description
- thumbnail
- sections[]

### セクション（Section）
- id
- courseId
- title
- order
- videos[]

### 動画（Video）
- id
- sectionId
- title
- description
- youtubeVideoId
- duration
- order
